Shack 🛖

~~~

Shack is being rebuilt as a small, familiar terminal editor 
for macOS and Linux, including SSH and tmux. Discoverable commands, 
previewable bulk edits, and useful language intelligence without 
mandatory configuration are the product priorities.

Distribution targets one executable. No editor runtime, Lua, Wasmtime, 
Node.js, or Python installation is required for ordinary editing. 
Language servers are optional external processes with their own 
dependencies and resource use.

~~~
