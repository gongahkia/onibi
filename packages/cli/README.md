# KelpClaw CLI

Install:

```sh
npm install -g @kelpclaw/cli
kelp-claw doctor
```

Upgrade:

```sh
npm update -g @kelpclaw/cli
kelp-claw version
```

Release artifacts include the `kelp-claw` binary, bundled KelpClaw workspace
modules, and the production dependency closure generated by the package smoke
script. Raspberry Pi field binaries are released separately as `kelp-pi-aarch64`
assets.

See `docs/cli-install.md` in the repository for npm and Homebrew tap guidance.
