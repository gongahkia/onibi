Built for deliberate delivery

A small surface, with strict boundaries.

Arachne exposes a terminal client, Rust SDK, and C ABI while keeping protocol versioning, contact verification, and state handling explicit.

Messages and attachments

Protocol posture

Be precise on the wire.

The v1 core schema uses definite-length CBOR arrays. Unknown fields, unsupported versions, trailing bytes, and malformed encodings are rejected.

ExplicitCapabilities and delivery choices are opt-in.
BoundedInputs and queues carry concrete limits.
VersionedExtensions require negotiated support.
