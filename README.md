# Shack

**Atomweight Terminal Text Editor IDE with Sensible Day 1 Defaults**

Shack is being rebuilt as a small, familiar terminal editor for macOS and Linux,
including SSH and tmux. Discoverable commands, previewable bulk edits, and useful
language intelligence without mandatory configuration are the product priorities.

Distribution targets one executable. No editor runtime, Lua, Wasmtime, Node.js,
or Python installation is required for ordinary editing. Language servers are
optional external processes with their own dependencies and resource use.

This checkout is under active development. The former Zenbu framework is preserved
in Git history and the local `archive/zenbu-before-shack` branch.

See [the product contract](docs/PRODUCT.md) and [architecture](docs/ARCHITECTURE.md).
